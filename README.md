# Calculator Web Application

A simple and responsive Calculator Web Application built using HTML, CSS, and JavaScript.

## Features

- Addition, Subtraction, Multiplication, and Division
- Interactive User Interface
- Responsive Design
- Clear Screen Functionality
- Keyboard Support
- Hover Effects and Modern Styling

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser

## Project Description

This project was created as part of the CodeAlpha Frontend Development Internship. The calculator performs basic arithmetic operations and provides a clean and user-friendly interface.
